# MazeRun

Unityで制作した、ランダム生成される迷路を制限時間内に駆け抜ける  
タイムアタック型のアクションゲームです。

## ゲーム概要
- ランダム生成される迷路を探索しながらゴールを目指す
- コインを集めてステータスを強化できる
- プレイごとに迷路構造が変化し、毎回異なる戦略が生まれる

## 実装した主な機能
- 迷路のランダム生成
- プレイヤー移動・スタミナ・速度などのステータス管理
- コイン収集と強化システム
- タイムアタック機能
- UI切り替え、レコード保存、ヒント表示
